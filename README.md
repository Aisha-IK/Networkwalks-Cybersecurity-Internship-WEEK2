---

## 🔍 Methodology & Lab Highlights

### 1. Reconnaissance & Footprinting (Phase 1)
* Conducted passive information gathering using **theHarvester** to identify publicly exposed metadata, subdomains, and host records.
* Analyzed attack surface visibility prior to initiating active network probes.

### 2. Scanning & Network Discovery (Phase 2)
* Executed active host discovery and TCP/UDP port enumeration across the target local LAN subnet using **Nmap** and **Zenmap**.
* Identified active IP addresses, associated MAC addresses, open ports, and running network services.
* Generated and exported a visual **Network Topology Map** in Zenmap to document host relationships and routing paths.
